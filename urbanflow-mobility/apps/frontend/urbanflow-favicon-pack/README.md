# 🌿 UrbanFlow — Pack Complet de Favicons & Icônes d'Application

Pack d'icônes généré pour l'application **UrbanFlow**, basé sur le logo vectoriel minimaliste avec courbe de flux et feuille éco-mobilité.

- **Couleur principale :** `#1A5F7A` (Deep Teal Blue)
- **Couleur de fond :** `#FFFFFF` / Transparent

---

## 📁 Contenu de l'archive

### 1. Racine (Installation standard)
Placez ces fichiers directement à la racine de votre site web (`/` ou `/public`) :
- `favicon.ico` : Format multi-résolution (16x16, 32x32, 48x48) pour tous les navigateurs.
- `favicon-16x16.png` : Onglets de navigateurs standard.
- `favicon-32x32.png` : Onglets Retina et favoris.
- `favicon-48x48.png` : Raccourcis bureau et signets Windows.
- `apple-touch-icon.png` (180x180) : Écran d'accueil iOS (iPhone / iPad).
- `android-chrome-192x192.png` : Écran d'accueil Android / PWA.
- `android-chrome-512x512.png` : Écran de chargement (splash screen) PWA.
- `android-chrome-maskable-192x192.png` & `512x512.png` : Icônes adaptatives avec zone de sécurité.
- `mstile-150x150.png`, `mstile-310x150.png`, `mstile-310x310.png` : Tuiles Windows.
- `site.webmanifest` : Manifest PWA préconfiguré.
- `browserconfig.xml` : Configuration Windows Tiles.
- `html_head_snippet.html` : Code HTML prêt à copier-coller dans votre `<head>`.

### 2. Dossier `/favicons-transparent/`
Toutes les tailles haute résolution sur fond transparent :
- 16x16, 32x32, 48x48, 64x64, 96x96, 128x128, 192x192, 256x256, 512x512

### 3. Dossier `/favicons-white-bg/`
Toutes les tailles sur fond blanc pur (`#FFFFFF`).

### 4. Dossier `/app-icons-teal-badge/`
Variante badge avec logo blanc sur fond plein sarcelle `#1A5F7A` (idéal pour déclinaisons applications natives / badges Store).

---

## 🚀 Guide d'installation

1. Décompressez le pack et copiez les fichiers à la racine de votre serveur web.
2. Ouvrez le fichier `html_head_snippet.html` et collez son contenu dans la section `<head>` de vos templates HTML.
3. Videz le cache de votre navigateur pour visualiser les changements.
